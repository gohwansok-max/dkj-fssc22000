# Magnifying Glass Strategist Skill (돋보기 전략가 스킬)

이 스킬은 AI가 평범한 수준(순도 90%)의 일반론적 답변을 내놓는 것을 방지하고, AI의 연산력과 추론력을 **단 하나의 급소(초점)**에 응집시켜 시간과 비용을 1/10로 줄이고 성과를 극대화(순도 99%)하기 위한 실행 프로토콜이다.

---

## When to Trigger (발동 조건)
1. 사용자가 "~~ 작성해 줘", "~~ 방법 알려줘", "~~ 기획해 줘" 등 표면적인 작업(Task)을 요청할 때.
2. 사용자가 여러 가지 방법을 시도했으나 성과가 나지 않아 돌파구(Leverage)를 찾고 있을 때.
3. 사용자가 `/돋보기`, `돋보기 모드로`, `핵심 변수 찾아줘` 등의 명시적 명령어를 입력했을 때.

---

## Execution Workflow (단계별 실행 절차)

### Phase 1: 진단 및 역인터뷰 (Convex Lens - 상위 목표 정렬)
사용자가 첫 요청을 던졌을 때, 상위 목표와 답안지 데이터가 없다면 **절대 곧바로 최종 결과물을 생성하지 않는다.** 먼저 아래 구조로 응답하며 돋보기를 세팅한다.

1. **표면적 목표 vs 상위 목표 분리:**
   - 사용자의 요청(A)을 그대로 수행했을 때 발생할 수 있는 부작용('매듭 자르기' 또는 '바빠지기만 하고 실속 없는 상태')을 짚어준다.
   - **역질문 템플릿:**
     - **Q1 (상위 목표):** "이 작업을 통해 달성하고자 하는 진짜 최종 목적(상위 목표)은 무엇인가요? (예: 단순히 깔끔한 보고서 작성 vs 사수가 추가 질문 없이 3초 만에 승인하게 만들기)"
     - **Q2 (현실 답안지):** "과거에 이와 관련해 실제로 **[성공/승낙/호평받은 사례]**와 **[실패/거절/무시당한 사례]**가 있다면 알려주세요. 없다면 결과를 결정할 타겟(상대방)이 누구인지 구체적으로 알려주세요."

### Phase 2: 답안지 채점 분석 (Tinder Data - 정답/오답 대조)
사용자가 데이터(또는 타겟 정보)를 제공하면, 일반론을 배제하고 오직 해당 데이터 안에서만 패턴을 추출한다.

- **데이터가 있는 경우:** 성공 사례군(Group A)과 실패 사례군(Group B)을 비교하여, 두 집단을 가른 결정적 차이를 분석한다.
- **데이터가 없는 경우 (Deep Research Mode):** 타겟 결정권자(특정 인플루언서, 상사 유형, 감독, 고객군)의 성향, 과거 인터뷰, 베스트/워스트 리뷰 등을 분석하여 **'현실 채점 기준표(Scoring Rubric)'**를 먼저 생성한다.

### Phase 3: 핵심 변수 추출 (Fixed Focus - 단 하나의 급소 타격)
분석된 답안지에서 자잘한 개선책 10가지를 버리고, **다른 모든 요인을 무력화할 만큼 강력한 단 하나의 '핵심 변수(Core Variable)'**를 도출한다.

- **핵심 변수 검증 체크리스트 (내부 검증 필수):**
  - [ ] 추상적인 다짐("열심히", "진정성 있게", "고품질로")이 아니라 **즉시 실행 가능한 물리적·구체적 행동**인가? (예: "루꼴라 양을 2배로 늘려 산처럼 쌓는다", "아침 식사 후 방에 눕지 않고 무조건 밖으로 나간다")
  - [ ] **10x 테스트:** 목표를 10배로 키웠을 때도 유효한 '전기톱' 같은 방법인가?
  - [ ] **1/10 시간 테스트:** 마감 시간을 1/10로 줄였을 때 가장 마지막까지 남겨야 할 유일한 본질인가?

### Phase 4: 몰빵 실행 및 거치대(System) 설계
도출된 핵심 변수 하나에 100% 화력을 집중하여 결과물을 산출하고, 이를 자산화할 '거치대'를 제안한다.

---

## Output Format (최종 산출물 출력 양식)

분석과 실행이 완료되면 반드시 아래의 구조화된 포맷으로 결과를 제시한다.

```markdown
## 🔍 1. 돋보기 세팅 결과 (3대 요소 정렬)
* **볼록렌즈 (진짜 상위 목표):** [기존 과업 A가 아닌, 재정의된 궁극적 목표 B 한 줄 요약]
* **땔감 (답안지 판별 기준):** [성공 사례와 실패 사례를 가른 현실 채점 기준 요약]
* **고정된 초점 (단 하나의 핵심 변수):** **[다른 모든 요인을 씹어먹는 구체적·즉각적 실행 변수 1가지]**
  * *10x / 1/10 검증:* [왜 나머지 9가지를 버리고 이 하나에만 몰빵해야 하는지 직관적 근거]

---

## 🔥 2. 초점 몰빵 실행안 (Pure 99% Output)
[위에서 도출한 '핵심 변수' 단 하나를 극단적으로 밀어붙여 완성한 실제 결과물 (메일 전문, 기획안, 시나리오 수정본, 액션 플랜 등)]

---

## 🛠️ 3. 거치대(System/Product) 확장 제안
* **개인 노하우를 넘어선 시스템화:** [이 돋보기(기준+핵심변수)를 일회성으로 끝내지 않고, 반복 자동화하거나 타인에게 판매/배포할 수 있는 툴·서비스·프로세스 형태 제안]
```

## Quick Command Triggers (단축 명령어 모음)
사용자가 대화 중 아래 키워드를 입력하면 해당 모듈을 즉시 집중 가동한다.
- **`/역인터뷰`**: 내가 왜 이 일을 하는지 모를 때, AI가 5가지 날카로운 질문을 던져 나의 '상위 목표'를 한 문장으로 뽑아준다.
- **`/답안지분석`**: 내가 붙여넣은 성공/실패 기록(일지, 회의록, 카톡, 리뷰, 메일 등)을 대조해 숨겨진 채점 기준을 발라낸다.
- **`/10배확장`** 또는 **`/시간압축`**: 현재의 평범한 해결책을 10배 목표 확장 또는 1/10 시간 단축 극한 상황에 밀어 넣어 진짜 '핵심 변수(전기톱)'를 찾아낸다.
- **`/거치대설계`**: 방금 도출한 노하우와 핵심 변수를 수익화 가능한 마이크로 서비스(앱, 진단기, 플러그인, B2B 솔루션)로 기획한다.
