# 공용 메뉴 레이아웃 검증 기록

- 검증일: 2026-08-19
- 대상: `docs-center.html` 공용 상단 메뉴
- 수정: 브랜드·바로가기 영역과 전체 GNB를 독립 행으로 분리하고, 메뉴 행에 수평 스크롤 허용을 적용함.

| 검증 항목 | 결과 |
|---|---|
| 헤더·브랜드·바로가기 행 배치 | 정상 — 브랜드와 바로가기 버튼은 첫 행에 배치 |
| 전체 GNB 행 배치 | 정상 — 두 번째 행에 독립 배치 |
| 메뉴 항목 겹침 | 없음 — 11개 항목의 좌표와 폭 교차 확인 |
| 1265px 로컬 화면 | 정상 — GNB 폭 1233px, 가로 스크롤 폭과 표시 폭 일치 |
| 1024px 이하 대응 | 햄버거 메뉴 전환 및 바로가기 버튼 숨김 규칙 적용 |

공용 `dkj-hub.css`를 참조하는 12개 허브 화면의 CSS 버전을 `v=49`로 갱신해 새 스타일을 즉시 다시 내려받도록 구성했다.
