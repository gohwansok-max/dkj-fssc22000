# FSSC 22000 심사 대비 보완 권고 및 엑셀 업로드 검증

**작성일:** 2026-08-18 (KST)  
**대상:** 동김제농협 스마트 HACCP·FSSC 22000 정기 관리 알림

## 1. 화면 표시 문제 조치

정기 알림 화면이 기본 HTML처럼 표시된 원인은 **정기 알림 기본 CSS가 누락**되고, 공용 내비게이션 CSS 파일도 참조 경로에 존재하지 않았기 때문입니다. 기본 스타일을 복구하고 공용 내비게이션 스타일 파일을 추가했으며, CSS 자산 버전을 갱신해 캐시된 이전 파일 대신 새 파일을 내려받도록 조치했습니다.

공개 페이지에서 두 CSS 파일의 HTTP 200 응답, 정기 알림 영웅 영역의 그라데이션 적용, 공용 내비게이션의 정상 렌더링을 확인했습니다.

## 2. FSSC 22000 심사 대비 보완 우선순위

FSSC V6의 핵심 추가 요구사항에는 품질관리, 설비관리, 식품안전·품질문화, 식품손실·폐기, 비상 커뮤니케이션과 함께 식품방어, 식품사기 완화, 알레르겐관리, 환경모니터링 및 교차오염 방지가 포함됩니다.[1] 현재 정기 관리 알림은 검교정·자가품질검사·환경모니터링·보건증의 **예정일 중심 관리**에 유효하므로, 아래 기능을 추가하면 심사 증빙의 완결성이 높아집니다.

| 우선순위 | 보완 기능 또는 관리 항목 | 심사 증빙 효과 |
|---|---|---|
| 1 | **환경모니터링 결과·추세 관리**: 구역/채취점별 결과, 기준 초과, 재검, 원인분석·CAPA 효과성 | 단순 일정 관리에서 결과 기반 검증 체계로 전환 |
| 2 | **계측기·설비 마스터**: 관리번호, 허용오차, 교정성적서, 수리·PM 이력, 사용중지 상태 | 설비관리와 검교정 유효성 증명 강화 |
| 3 | **자가품질검사·제품 품질 대시보드**: 규격, 시험성적서, 부적합, 추세, 출하판정 연계 | 품질 및 수량 관리의 체계적 모니터링 증거 확보 |
| 4 | **위생·보건 적격성 관리**: 작업자별 보건증, 개인위생 점검, 교육·평가, 미이수자 작업제한 | 인적자원 적격성과 위생관리 연결 |
| 5 | **CAPA 효과성 확인 알림**: 원인분석, 조치기한, 효과성 검증일, 재발 여부, 미종결 건 | 심사에서 자주 보는 조치의 종결 품질 보완 |
| 6 | **식품방어·식품사기·공급업체 재평가 주기**: 취약성 평가, 변경사항, 원료 위험등급, 승인상태 | FSSC 추가 요구사항의 정기 재평가 증빙 확보 |
| 7 | **식품안전·품질문화 지표**: 현장 인터뷰, 교육 참여, 제안·보고, 행동관찰, 경영검토 결과 | 문화 요구사항을 측정 가능한 증거로 전환 |
| 8 | **V7 전환 갭 분석표**: ISO 22002-100:2025 및 식품제조 ISO 22002-1 기준, 담당·증빙·완료일 | 차기 전환심사 준비를 선행 관리 |

> 권장 순서는 **환경모니터링 결과·CAPA → 설비/교정 마스터 → 품질시험 추세 → 위생·보건 적격성**입니다. 현재 정기 알림의 예정일·사전 알림 기능을 각 기능의 기한 관리 공통 엔진으로 재사용할 수 있습니다.

FSSC V7은 2026년 5월 공개되었으며, V6 심사는 2027년 4월 30일까지 허용됩니다. V7 전환심사는 2027년 5월 1일부터 2028년 4월 30일까지 진행됩니다.[2] 다음 심사 적용 버전은 인증기관 일정으로 확인하되, 지금부터 PRP 갭 분석을 병행하는 것이 효율적입니다. V7은 ISO 22002-100:2025와 식품제조용 ISO 22002-1을 적용하고, 포장 설계·식품손실 및 폐기 저감 관련 요구사항을 강화했습니다.[2] [3]

## 3. 엑셀 일괄 업로드 검증 결과

| 검증 항목 | 결과 |
|---|---|
| 업로드 파일 | 11개 필수 열을 포함한 `.xlsx` 파일 |
| 테스트 행 | 계측기 검교정, 자가품질검사, 환경모니터링, 보건증 각 1건씩 총 4건 |
| 업로드 결과 | 화면에 **“4개 관리 항목을 일괄 반영했습니다.”** 표시 |
| 저장·화면 검증 | 관리 항목 7건에서 11건으로 증가, 테스트 ID 4건과 화면 행 4건 일치 |
| 정리 | 테스트 항목 4건 제거 후 기본 관리 항목 7건 상태로 복원 |

테스트는 운영 데이터 오염을 막기 위해 **브라우저 격리 저장소**에서 수행했습니다. 따라서 운영 Firebase 기록과 실제 이메일 발송 대상에는 테스트 항목이 남지 않았습니다. 실제 사용 시 로그인한 상태에서 동일한 엑셀 양식으로 업로드하면 클라우드 동기화 대상에 포함됩니다.
