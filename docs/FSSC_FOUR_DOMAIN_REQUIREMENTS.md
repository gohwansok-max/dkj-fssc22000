# FSSC 22000 4개 관리영역 설계 기준

## 공식 FSSC 자료

FSSC 공식 V7 추가요구사항 페이지는 기존 추가요구사항이 V7에도 계속 적용되며, Food Defense, Food Fraud Mitigation, Management of Allergens, Environmental Monitoring 및 교차오염 방지 항목을 포함한다고 명시한다. 심사 화면은 각 영역의 위험평가, 완화조치 또는 관리계획, 실행기록, 검증과 검토 증빙을 연결해야 한다.

- FSSC V7 Additional Requirements: https://www.fssc.com/fssc-22000/fssc-22000-v7-additional-requirements/
- FSSC V6 Additional Requirements: https://www.fssc.com/fssc-22000/fssc-22000-additional-requirements/

## 프로젝트 내 확인된 문서·서식

| 관리영역 | 절차서·기록 |
|---|---|
| 식품방어 | 절차서 DKJ-P-13, FR-031 식품방어 취약성 평가표, FR-032 식품방어 실행계획서 |
| 식품사기 | 절차서 DKJ-P-14, FR-033 식품사기 취약성 평가표, FR-034 식품사기 예방 실행계획서 |
| 환경모니터링 | 절차서 DKJ-P-16, FR-037 환경모니터링 계획서, FR-038 환경모니터링 결과 및 Trend표 |
| 알레르기 관리 | 절차서 DKJ-P-15, FR-035 알레르겐 관리 프로그램 및 원료/제품 목록 |

DKJ-P-16 발췌문은 환경모니터링의 산출물로 계획서, 검사결과, Trend표, 개선조치 기록, 경영검토 입력자료를 명시한다. 각 모듈 화면은 위험 또는 취약성 평가, 계획, 현장 점검 또는 검사기록, 이탈·시정조치, 검증·경영검토 상태를 한 화면에서 확인 가능하게 설계한다.

## 로컬 UI 초기 검증

식품사기 탭의 입력 폼과 4개 영역 대시보드는 정상 렌더링됐다. 다만 첫 저장 클릭 후 요약 수치가 0으로 남아 있어 서비스워커의 구버전 응답 또는 스크립트 초기화 문제를 콘솔과 네트워크 로드 상태로 추가 확인한다.

브라우저 진단에서 `fssc-four-domain.js?v=1`과 `DkjRecordStore` 객체가 정상 로드됐고 허브 기록 수는 0건이었다. 화면 하단의 서비스워커 새 버전 안내 배너가 저장 버튼을 가리는지 확인하기 위해 폼 제출 이벤트를 직접 검증한다.

폼 제출 이벤트를 직접 검증한 결과 식품사기 실행·검증 이력 1건이 `FSSC-AR-HUB`에 저장됐고, 요약카드 수치와 이력 목록에 대상·검증유형·조치·증빙·담당자·다음 검토일이 정상 반영됐다. 이후 배포 전 로컬 테스트 기록을 삭제한다.

환경모니터링 탭에서 FR-037 계획서, FR-038 결과·Trend표, DKJ-P-16 절차서 링크와 채취지점·위생구역·시험항목·결과·조치·재채취·증빙 입력 항목이 모바일 화면에 정상 표시됐다. 로컬 테스트 기록 삭제 후 화면 수치는 새로고침 시 정상 반영된다.

식품방어 탭에서 FR-031·FR-032·DKJ-P-13 링크, 출입·방문객·원료/제품·유틸리티·기록보안 점검 유형, 이탈·시정조치 입력이 확인됐다. 알레르기 탭에서 FR-035·DKJ-P-15·DKJ-W-008 링크, 원료/제품·알레르겐·보관동선·전환세척·라벨 확인 및 이탈조치 입력이 모바일 화면에 정상 표시됐다.
