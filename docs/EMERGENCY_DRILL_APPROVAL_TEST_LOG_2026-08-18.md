# 모의훈련 결과보고서 결재선 기능 검증 기록

- 검증일: 2026-08-18 (KST)
- 대상: `emergency-drills.html`, `js/emergency-drills.js`, `js/dkj-approval.js`
- 환경: 로컬 격리 화면의 테스트 기록

| 검증 항목 | 결과 | 확인 내용 |
|---|---|---|
| 결재선 입력 | 통과 | 작성·검토·승인자 입력 제어가 표시됨 |
| 결재 요청 전 통제 | 통과 | 초안 저장 전에는 전자서명 단계를 표시하지 않음 |
| 결재 요청 후 잠금 | 통과 | 본문 입력 필드가 비활성화되고 3단 결재 제어가 표시됨 |
| 3단 전자서명 | 통과 | 작성·검토·승인 3단계 모두 서명 상태·일시가 보고서 결재표에 표시됨 |
| 최종 잠금 | 통과 | 3단 서명 후 최종 승인·잠금 상태가 보고서에 표시되고 잠금 제어가 비활성화됨 |
| 결재표·감사이력 표시 | 통과 | 최종 보고서에 작성·검토·승인자, 서명 상태·일시, 최종 승인·잠금 상태와 무결성 정상 감사이력이 표시됨 |
