# FR-016·FR-039 제품회수 연동 테스트

2026-08-16 로컬 브라우저 저장소에 제품 LOT `FIN-20260816-A`, 품명 `테스트 샐러드믹스`, 부적합 수량 30, 처리 `격리`, 부적합유형 `포장 라벨 오류`인 FR-039 테스트 기록을 저장했다. 다음 단계에서 LOT 조회 시 FR-039 제품격리 30이 표시되고, 모의회수 적용 시 제품 격리수량·회수 대상·위치별 합계·수량차이에 반영되는지 검증한다. 이후 FR-016 초안이 제품명, LOT, 회수 대상량, 회수 범위, 조치 내용과 함께 생성되는지 확인하고 모든 테스트 기록은 로컬 브라우저 저장소에서 제거한다.

첫 LOT 조회에서는 화면의 FR-039 요약·상태 문구가 이전 스크립트 형식으로 남고 테스트 기록이 표시되지 않았다. 최신 페이지의 스크립트 버전과 `DkjRecordStore.list('FR-039')` 반환값을 확인한 뒤, 서비스워커 캐시를 해제하고 재검증한다.

진단 결과 현재 저장소에는 FR-039 테스트 기록이 존재했고 리소스 URL도 `traceability-hub.js?v=42`였으나, 서비스워커가 V42 요청에 이전 캐시 응답을 반환한 것으로 판단됐다. 로컬 서비스워커를 해제하고 고유 쿼리 경로로 최신 화면을 다시 열어 기능을 재검증한다.

서비스워커 해제 후 최신 화면에는 FR-039 제품격리와 FR-016 초안 UI가 정상 표시됐다. 테스트 LOT를 다시 입력한 상태에서 추적 실행, 모의회수 자동적용, FR-016 초안 생성과 양식 자동 채움을 순서대로 검증한다.

최신 V42 로컬 화면에서 LOT `FIN-20260816-A`를 조회한 결과 FR-039 제품격리 30이 결과표에 표시됐다. ‘현재 추적 결과 적용’ 후 회수대상 30, 격리수량 30, FR-039 제품격리 30, 위치별 합계 30, 수량차이 0이 자동 입력된 것을 확인했다. 이어 FR-016 초안 생성 시 제품명·LOT·대상수량·회수범위·조치가 양식에 전달되는지 검증한다.

FR-016 초안 페이지에서 제품명 `테스트 샐러드믹스`, LOT `FIN-20260816-A`, 회수대상량 30, 작성자, 회수 범위와 조치 문구가 자동 채워진 것을 화면으로 확인했다. 로컬 테스트 FR-039·FR-016 기록 제거 명령은 브라우저 콘솔 시간초과가 발생해, 다음 단계에서 저장소 목록을 별도 확인하고 잔여 테스트 기록만 정리한다.
