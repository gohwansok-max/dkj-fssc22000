# FR-015 부적합 원부자재 처리기록 연동 테스트

2026-08-16 로컬 브라우저에서 LOT `NC-20260816-A`, 처리수량 25 kg, 처리결과 `격리`, 위치 `부적합 격리구역`인 임시 FR-015 기록을 저장했다. 첫 조회에서는 이전 서비스워커가 `traceability-hub.js` 구버전을 반환해 FR-015 기록이 표시되지 않았다. 브라우저 서비스워커를 해제하고 최신 V41 스크립트로 다시 로드한 뒤, LOT 추적·수량대조·모의회수 자동 적용을 재검증한다. 이 테스트 기록은 로컬 브라우저 저장소에만 존재하며 운영 데이터에는 반영되지 않았다.

서비스워커 해제 후에도 기존 `traceability.html`의 캐시된 V40 본문이 표시되는 현상을 확인했다. 다음 검증에서는 고유 쿼리 문자열로 페이지를 다시 열어 HTML과 V41 스크립트가 함께 갱신됐는지 확인한다.

고유 쿼리 문자열로 페이지를 다시 열고 리소스를 확인한 결과, `traceability-hub.js?v=41`이 로드됐으며 로컬 저장소의 FR-015 테스트 기록도 정상 조회됐다. 이전 조회 실패는 기존 V40 스크립트가 남아 있던 캐시 상태에 따른 것이었다.

최신 V41 로직으로 LOT `NC-20260816-A`를 조회한 결과, 원료 입고·생산·출하 기록이 없어도 FR-015 처리기록 1건이 표시됐고 `FR-015 격리 25`, 회수 대상 25 kg, 정상재고·출하 0으로 자동 집계됐다. 이로써 FR-015 단독 격리 LOT도 모의회수 대상으로 산정되는 것을 확인했다.

`현재 추적 결과 적용` 실행 시 FR-015 격리 25 kg이 격리 수량, 회수/확보 수량, `FR-015 부적합 격리` 위치수량에 모두 자동 적용됐다. 위치 분류 합계는 25 kg, 회수 대상 대비 수량차이는 0으로 계산됐다. 원료 입고·생산·출하 기록이 없는 부적합 원료 LOT에 대해서도 모의회수 수량대조가 완성되는 것을 확인했다.
