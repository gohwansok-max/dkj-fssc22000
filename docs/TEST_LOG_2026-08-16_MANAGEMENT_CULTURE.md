로컬 경영검토·식품안전문화 화면은 모바일 레이아웃에서 경영검토·식품안전문화 탭, CAPA·모의회수·제품회수·추적점검 성과요약, 5개 문화 차원 평가, 초안·승인·잠금 버튼을 정상 렌더링했다. 경영검토 초안 저장을 위해 검토기간, 회의일, 주재자, 참석자, 입력요약, 의사결정, 후속조치, 책임자, 기한, 효과검증, 작성·검토·승인자 필수값을 입력했다.
모바일 메뉴 겹침은 업무 콘솔 헤더가 72px 고정 높이와 비줄바꿈 상태로 다수의 바로가기를 한 줄에 배치해 발생했다. 공통 헤더의 자동 줄바꿈 전환을 최대 1360px로 확대하고 CSS 버전을 갱신했으며, PWA 프리캐시도 재생성했다. 로컬 브라우저는 기존 서비스워커가 이전 CSS를 반환해 새 서비스워커 해제 후 재검증이 필요하다.
서비스워커 해제·프리캐시 재생성 후 1280px 로컬 화면에서 공통 헤더 높이는 111.344px, 헤더와 우측 메뉴의 flex-wrap은 wrap, scrollWidth와 clientWidth는 모두 1265px로 확인됐다. 즉 모든 바로가기 버튼이 여러 줄로 배치되고 가로 넘침·겹침이 제거됐다.
운영 GitHub Pages는 index.html의 CSS 버전 v40을 참조하지만, 첫 재확인 시 헤더는 72px·nowrap이며 scrollWidth 1409px로 이전 CSS 본문을 반환했다. GitHub Pages CDN/배포 반영 지연 가능성을 확인하기 위해 추가 대기 후 재검증한다.
후속 서비스워커 갱신 배포 후 운영 GitHub Pages에서 PWA 버전 v40을 확인했다. 1280px 기준 헤더 높이 111.344px, 헤더·메뉴 flex-wrap=wrap, scrollWidth=clientWidth=1265px로 확인되어 상단 메뉴의 가로 넘침·겹침이 제거됐다.
