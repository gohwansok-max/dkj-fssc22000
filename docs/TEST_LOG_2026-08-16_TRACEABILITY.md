# 추적성 검증·모의회수 화면 테스트 기록

2026-08-16 로컬 정적 사이트에서 `traceability.html`을 확인했다. LOT 조회, 생산·출하 연결 등록, 수량대조, 모의회수 검증 입력과 저장 영역이 모두 표시됐으며, 모바일 화면에서는 입력 영역이 한 열로 재배치됐다. 초기 검증에서 브랜드 로고가 과도하게 확대되는 현상을 확인해 페이지 전용 로고 크기 규칙을 추가했고, 보완 후 헤더와 본문이 정상 표시됐다.

## 통합 기능 검증

로컬 저장소에 임시 FR-014 입고 일보(양상추, LOT `RAW-20260816-A`, 120 kg)를 넣고 화면을 재로딩했다. 원료 선택지에 해당 일보가 자동 표시됐고, 생산 LOT `P-20260816-01`, 생산수량 100, 출하수량 80, 재고 20을 연결기록으로 저장했다. 이후 원료 LOT 조회에서 원료 입고 1건·생산 LOT 1건·출하대상 80·확보재고 20과 수량대조(입고 120 / 생산 100 / 출하 80 / 재고 20)가 정상 출력됐다. 해당 추적 결과를 모의회수에 적용해 4개 확인항목, 통지·격리 조치, 개선조치를 포함한 검증 기록을 저장했고 2시간 목표 충족 및 스냅샷 보존을 확인했다. 테스트 후 로컬 임시 데이터는 제거했다.

## FR-014 모바일 간편 흐름 검증

로컬 FR-014 기록(`양상추`, LOT `MOB-20260816-A`, 120 kg)을 대상으로 `from014`·`lot`·`mode=quick` 파라미터로 추적성 화면을 열었다. 상단 간편 카드에 입고일·공급업체·수량이 표시됐고, 원료 선택·LOT·완제품명·원료 투입량·등록자·모의회수 시나리오가 자동 입력됐다. ‘모의회수 시작’ 버튼 한 번으로 LOT 추적, 수량대조, 모의회수 대상 적용, 시나리오 입력 위치 이동이 정상 동작했다. 생산·출하 연결이 없는 상태에서는 출하·재고가 0으로 표시되어 현장 연결기록 작성 필요성을 명확히 알렸다.

## 심사 대비 시나리오·점검 항목 보강

- 6개 선택형 시나리오(라벨·알레르겐, 원료 미생물·잔류농약, CCP 이상, 냉장 온도이탈, 고객 클레임·이물, 공급업체 증빙 오류)가 모의회수 화면에 표시됨을 확인했다.
- 라벨·알레르겐 템플릿 선택 시 회수 사유, 초기 조치, 거래처 회수 요청 판단, 추적 안내 문구 및 모의 통지 기준이 자동 입력됨을 확인했다.
- FR-014 테스트 LOT 추적 후 회수 대상 적용 시 대상 LOT, 시작시각, 위치별 수량 기본값, 회수 범위 안내가 자동 연동됨을 확인했다.
- 위치별 수량 합계·수량차이 자동계산, 결정·연락·효과검증·증빙 참조 항목, 8개 필수 확인항목의 렌더링을 확인했다.
- 검증에 사용한 테스트 데이터는 로컬 브라우저 환경에서만 사용했으며 운영 데이터에는 저장하지 않았다.
