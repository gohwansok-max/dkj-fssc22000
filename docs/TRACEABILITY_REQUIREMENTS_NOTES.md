# 추적성 검증·모의회수 기능 설계 기준

## 공식 요구사항 참고

FSSC 22000 V6의 추가요구사항은 ISO 표준 및 GFSI 기준에 연계되며, 인증 조직은 FSMS 안에서 품질·수량을 체계적으로 모니터링하고 평가해야 한다. 또한 중대 사건 통지와 비상대응 프로세스를 요구한다. 추적성·회수 기능은 ISO 22000 기반 제품 추적성, 부적합 제품 통제, 비상대응 및 제품 회수 절차의 전자적 증빙을 보완하는 범위로 설계한다.

FSSC 공식 문서 페이지는 2026년 5월 FSSC 22000 V7이 공개됐음을 안내한다. 현재 사이트 표기는 V6이므로 본 기능은 현행 V6 절차서와 기록을 우선 연결하되, V7 전환 시 절차서·심사 기준을 재검토해야 한다.

## 시스템 반영 항목

| 항목 | 시스템 기능 |
|---|---|
| 정방향 추적 | 원료 LOT 또는 입고 기록에서 연결된 생산 LOT·완제품·출하 정보를 조회 |
| 역방향 추적 | 생산 LOT 또는 완제품 LOT에서 사용 원료 LOT·공급자·입고 기록을 조회 |
| 수량 대조 | 입고·생산·출하·재고 수량을 입력하고 회수대상·확보 가능 수량·회수율을 자동 계산 |
| 모의회수 | 회수 개시·종료시각, 대상 LOT, 유통처, 회수 수량, 격리, 통지·조치, 결과와 개선조치를 기록 |
| 증빙 | 연결된 일보의 작성번호·작성일·작성자·잠금상태와 추적 결과를 불변 스냅샷으로 저장 |
