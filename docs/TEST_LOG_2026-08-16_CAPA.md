CAPA 로컬 통합 검증을 시작했다. 원천기록 선택 목록에서 기존 FR-039 부적합품 기록을 선택하고 적용한 결과, LOT FIN-20260816-A, 수량 30, 기존 조치 격리가 CAPA 화면에 자동 반영됐다. 원천기록 연결 안내와 스냅샷 보존 안내도 표시됐다.
FR-039 연동 CAPA에 품목·격리위치·이탈내용·즉시조치·작성/검토/승인자·근본원인·CAPA·책임자·기한·효과검증·증빙·경영검토 항목을 입력했다. 다음 단계에서 초안 저장, 3단 결재, 종결 잠금 흐름을 확인한다.
CAPA 초안 저장 버튼을 브라우저 상호작용으로 실행한 뒤 자동 경고 또는 서비스워커 동작으로 페이지가 about:blank로 전환돼 즉시 화면 확인이 불가했다. 동일 버튼 클릭을 반복하지 않고 새 로컬 페이지에서 저장소 기록 여부와 스크립트 동작을 재검증한다.
CAPA 저장 후 작성 결재 버튼을 브라우저로 실행했을 때 자동 알림 또는 PWA 동작으로 클릭 대기가 시간초과됐다. 동일 동작을 반복하지 않고 새 세션을 열어 결재 이력·서명 저장 여부를 확인한다.
공통 결재 모듈은 결재 확정 시 확인창과 저장 완료 알림을 띄운다. 자동 브라우저에서는 이 상호작용이 시간초과로 이어졌으므로, 새 세션에서 서명·감사이력 저장 여부를 확인하고 실제 종결 잠금은 코드·저장소 단위로 검증한다.
작성 결재가 감사이력에 정상 저장된 것을 새 세션에서 확인했다. 검토 결재도 같은 확인창·알림 흐름으로 자동화 대기가 시간초과돼, 새 세션에서 검토 서명 저장 여부를 확인한다.
새 세션의 저장소 조회 결과 CAPA 초안 1건이 유지됐고, 원천은 FR-039, 상태는 즉시조치 완료, 작성 서명(writer) 1건과 감사이력 3건(SAVE·SIGN 포함)이 확인됐다. 검토·승인·종결잠금은 확인창이 포함된 후속 단계로 별도 검증한다.
자동 확인창 승인 방식으로 검토·승인 서명과 효과검증 완료·종결 요청을 실행했다. 저장소에는 writer/reviewer/approver 3단 서명과 상태 closed가 저장됐으며, 잠금 버튼은 활성화돼 있고 원인분석·CAPA·효과검증결과도 충족했다. 종결잠금은 별도 단일 동작으로 재검증한다.
종결 요청 상태 동기화 보완 후 새 로컬 세션에서 작성·검토·승인 3단 서명, 효과검증 완료, 종결·잠금을 검증했다. 저장소 결과는 locked=true, status=closed였으며 감사이력에 SAVE·SIGN·LOCK이 순서대로 남았다. 원천 FR-039 스냅샷과 LOT FIN-20260816-A, 수량 30도 CAPA 이력에 유지됐다.
