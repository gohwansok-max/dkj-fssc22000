# 콘솔 리팩터링 및 웹앱 검증 (2026-10-09)

## 변경

- `dkj-record-evaluator.js`: 기록 상태 판정을 DOM·저장소와 분리. 기존 `DkjConsole.evaluate(form, date)` 호출 방식 유지.
- `dkj-operation-calendar-model.js`: 콘솔과 휴무행 대장이 생산일 정규화·예외 우선순위를 공유.
- 정적 자원 버전 119, 대장 생성기의 스크립트 순서 및 서비스워커 프리캐시 갱신.
- FR-023의 심사 의견 `audit`와 감사이력 배열 `audit`의 충돌 수정. 새 입력 필드는 `auditInput`. 기존 문자열 의견은 화면을 불러올 때 호환 변환하고 인쇄에서도 읽는다. 저장 원본은 자동 변경하지 않는다. 기존 정상 감사이력 배열은 보존하며, 과거 문자열을 감사이력으로 재구성하지 않는다.
- 보고서 본문·표의 인원 INPUT이 직원 SELECT로 교체되면 사라지던 입력 리스너를 부모에 위임. 직원 선택값을 저장·재열기할 수 있다.
- 단위 회귀 테스트 추가 및 README 실행·검증 방법 정리.

## 검증 환경

Windows / Chrome headless / 로컬 HTTP 서버 / 별도 브라우저 프로필과 합성 데이터.
브라우저 검사에서는 Firebase 설정을 비활성화하고 외부 요청을 차단했다. 운영 계정·기록·클라우드는 변경하지 않았다. 인쇄 검사에서는 OS 인쇄창 대신 호출 횟수와 정본 HTML 생성을 확인했다.

## 검증 범위의 한계

실제 운영 Firebase의 기기 간 왕복 동기화, 실제 사용자 비밀번호·역할 배정, 텔레그램 메시지 전달, Google Drive 원본 권한, 실물 프린터 출력은 확인하지 않았다. 관련 인증·동기화·텔레그램 동작은 기존 모의 요청 회귀 테스트가 통과했다. 모든 화면의 모든 버튼 조합이나 모든 입력의 업무적 적합성을 증명하는 검사는 아니다.

배포는 main 병합 후 별도 확인이 필요하다. 이 변경은 검토용 초안 PR로 준비한다.
