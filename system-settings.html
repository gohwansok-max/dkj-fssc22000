💡 텔레그램 봇 토큰 및 Chat ID 확인 방법 (1분 완성 가이드)
1. 텔레그램 봇 생성 (Bot Token 발급):
• 텔레그램 검색창에 @BotFather 검색 후 대화 시작 (/start)
• /newbot 입력 → 봇 이름 및 아이디 설정 (예: dkj_haccp_bot)
• 생성 완료 시 주어지는 Use this token to access the HTTP API: 뒤의 긴 토큰 복사 후 위 [봇 토큰] 란에 붙여넣기

2. 내 Chat ID 확인:
• 텔레그램 검색창에 @userinfobot 검색 후 /start를 누르면 본인의 Id: 123456789 숫자가 나옵니다.
• 또는 위에서 만든 봇에게 먼저 아무 말(예: /start 또는 안녕)이나 보낸 후 Chat ID를 입력하고 [테스트 메시지 즉시 발송]을 눌러보세요!
